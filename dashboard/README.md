# appprovedor-dashboard

Painel web para gerenciar os provedores cadastrados no backend Acesseweb.

## EasyPanel

Crie um serviço Docker apontando para este repositório e configure:

```text
VITE_API_URL=https://sistema-app-provedor.5mos1l.easypanel.host/api
```

O container expõe a porta `80`.

## Desenvolvimento

```bash
npm install
npm run dev
```
